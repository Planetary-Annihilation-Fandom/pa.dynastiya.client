# Отзывчивость управления

Здесь собраны изменения для [задачи #5](https://github.com/Planetary-Annihilation-Fandom/pa.dynastiya.server/issues/5). Исходные файлы установленной игры не заменяются.

| Файл | Назначение |
|---|---|
| `control_feedback.css` | Общие мгновенные состояния контролов; отдельный список свойств для движения панелей HUD |

Подключение задаётся в `modinfo.json`: CSS через `global_mod_list` для всех представлений. Правила применяются и к обычному состоянию, чтобы убрать задержку при уходе курсора; они не меняют обработчики, геометрию, фокус или `pointer-events`. Приоритет проверки — лобби, главное меню и настройки.

Общие правила и результаты проверки находятся в серверном репозитории: `docs/ui/control-feedback.md`, `docs/ui/changes.md`. Изменения генератора планет вынесены в отдельную [задачу #11](https://github.com/Planetary-Annihilation-Fandom/pa.dynastiya.server/issues/11).
